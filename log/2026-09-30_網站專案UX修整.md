# 網站專案 UX 修整

**日期**：2026-09-30
**操作者**：Codex

## 變更內容

- 收斂會員頂部工具列，只保留必要的全域入口，網站切換器改為緊湊的單一控制區。
- 將全高網站側欄改為內容旁的 compact navigation card，降低視覺重量與空白浪費。
- 提升工作區表面、邊框、文字與主要動作對比，主互動回到 Argus 虹膜青。
- 新增第一次掃描的引導式空狀態，取代無意義的零值統計卡。
- 將掃描狀態改為繁體中文，並改善桌機與行動版的導覽層級。

## 原因

使用者指出初版網站專案工作區外觀不佳且 UX 退步；實際截圖也顯示頂部擁擠換行、側欄過重、內容對比不足與空狀態缺少下一步指引。

## 影響範圍

- 只調整會員網站工作區的 React 呈現與 CSS，不變更後端 API、資料模型、掃描流程或計費。
- 所有既有專案路由、操作與權限行為維持不變。

## 驗證方式

- 執行 ESLint、TypeScript、Vitest 與 Node 22 production build。
- 使用 Playwright 實際登入，分別以 1440×1000 與 390×844 截圖檢查。
- 確認桌機與行動版皆無水平捲動，且第一份掃描 CTA、網站切換與側欄導覽可見。
