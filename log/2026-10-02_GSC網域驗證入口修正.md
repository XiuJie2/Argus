# GSC 網域驗證入口修正

**日期**：2026-10-02
**操作者**：Codex

## 變更內容

- 在網站專案設定加入可操作的「網域驗證與 Search Console」區塊，顯示驗證狀態、方法與期限。
- 提供 GSC OAuth、property 選擇，以及帶入目前 hostname 的 DNS／HTML 驗證入口。
- 讓 GSC status API 即使尚未連線，也回傳目前專案所涵蓋的有效 `VerifiedDomain`。

## 原因

先前只有後端 GSC 與網域驗證能力，網站專案工作區沒有連線按鈕或驗證狀態，會員實際上無法從專案流程完成或確認網域驗證。

## 影響範圍

- 影響網站專案設定頁、既有網域驗證頁的返回流程，以及 GSC status API 回應。
- 不改變驗證安全邊界；仍只有涵蓋 hostname 的有效驗證可開啟主動掃描，GSC 仍要求 `siteOwner`。

## 驗證方式

- 執行 integrations 測試、後端 lint、Django migration／系統檢查與 OpenAPI 產物更新。
- 執行前端 lint、typecheck 與單元測試；此 Linux 容器缺少 PowerShell 與 Chromium 系統函式庫，因此 production build 與截圖留待 CI／具備相依套件的環境確認。
