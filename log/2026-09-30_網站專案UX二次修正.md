# 網站專案 UX 二次修正

**日期**：2026-09-30
**操作者**：Codex

## 變更內容
- 移除首次掃描空狀態中的裝飾性雷達圖、三步驟編號與重複主要按鈕。
- 將網站切換器、專案側欄、專案卡片與資料摘要改成較平面、緊湊的會員工具介面。
- 保留網站專案側邊導覽，但取消浮動玻璃卡片外觀與無資訊價值的狀態圓點。
- 修正手機版 grid row 被工作區最小高度拉伸，導致導覽與內容之間出現大片空白的問題。

## 原因
前版雖完成網站專案資訊架構，但裝飾元素、卡片層級與大面積空狀態過多，呈現出制式 AI dashboard 觀感，且破壞 Argus 原本較克制的會員區體驗。

## 影響範圍
- 僅調整網站專案工作區的 JSX 文案結構與 `74-project-workspace.css`。
- API、路由、掃描、計費與資料模型均未變更。

## 驗證方式
- 使用 Playwright mock API 產生 1440×900 與 390×844 實際畫面截圖並逐一檢視。
- 兩種 viewport 均確認沒有水平溢出；手機版內容緊接在專案導覽之後。
- 執行前端 lint、型別檢查與單元測試。
