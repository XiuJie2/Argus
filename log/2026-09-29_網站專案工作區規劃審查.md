# 網站專案工作區規劃審查

**日期**：2026-09-29
**操作者**：Codex

## 變更內容

- 新增會員區網站專案工作區的修訂實作規劃。
- 依現有掃描、網域驗證、計費、歷史 API 與前端路由校正原提案。
- 補上舊資料 migration、精確 hostname 邊界、問題指紋與可比較性、外部整合 go/no-go、測試及回滾策略。
- 更新專案記憶索引與決策摘要。

## 原因

使用者要求先審查現有專案，再獨立評估會員區改版提案並輸出經優化的完整規劃，而不是直接採納原提案。

## 影響範圍

- 僅新增規劃、記憶與任務紀錄，沒有修改程式、資料庫、API、UI 或正式環境。
- 後續實作應以規劃中的 Release 0–1 為起點，外部整合不得被視為已完成能力。

## 驗證方式

- 對照 `backend/apps/scans` 的 model、serializer、view、service 與 URL 實作。
- 對照目前會員 Dashboard、歷史、掃描與網域驗證路由。
- 重新核實 Cloudflare、Google Search Console 與 GA4 官方文件。
- 執行 Markdown 連結、敏感字串、diff 與 repository status 檢查。
