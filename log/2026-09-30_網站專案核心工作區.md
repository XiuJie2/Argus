# 網站專案核心工作區

**日期**：2026-09-30
**操作者**：Codex

## 變更內容

- 新增 `SiteProject` 與舊掃描回填 migration，讓掃描成為網站專案的診斷快照。
- 新增 owner-scoped 專案 CRUD／封存 API，並讓掃描、Dashboard、finding 與歷史支援 project 篩選。
- 新增所有網站、網站新增、頂部切換器、專案側欄，以及總覽、掃描、問題、歷史報告、設定頁。
- 保留舊會員頁與掃描深連結，專案建立與封存不觸發計費。
- 同步模組規則、接手文件、競賽需求／設計／差異文件與專案記憶。

## 原因

使用者要求把會員區完整改為以網站專案為核心的持續診斷工作區，參考 Sitechecker 的網站切換與側欄結構，但維持 Argus 自有視覺與掃描能力。

## 影響範圍

- `scans` model、migration、serializer、API、admin 與測試。
- 登入後頂部導覽、React routes、網站專案頁與樣式。
- 現有掃描授權、點數預扣／結算／退款與 worker 狀態機不變。

## 驗證方式

- Django migration check、專案 API 測試、scans／billing 回歸測試與 system check。
- 前端 ESLint、TypeScript、Vitest、Node 22 production build。
- 啟動應用後以瀏覽器檢查桌機與行動版網站工作區並截圖。
